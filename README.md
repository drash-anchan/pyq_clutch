##  About the Project

Engineering students at MIT Manipal frequently lose crucial study time hunting through disorganized Google Drives, Telegram channels, and scattered WhatsApp PDFs when studying for high-stakes 3rd-semester Endsem exams. 

**PYQ Vault** solves this with a **Subject-First Architecture**:
- Students select the exact subject they are studying (e.g., Data Structures).
- They view an independent, descending timeline of examination years (2025, 2024, 2023, 2022).
- Under each year, all available paper variants (Regular and Makeup) are indexed with first-page previews and one-click downloads.
- No clutter from other semesters or midsems. Fast, reliable, and distraction-free.

---

##  Implemented Features

- **Subject-First Navigation**: Clean subject portals that preserve independent examination year timelines.
- **Multiple Paper Variants**: Clearly distinguished **Regular** and **Makeup** question papers.
- **Interactive 3D Card Centerpiece**: Freely rotatable 3D hero paper stack powered by cursor physics and smooth mobile touch gestures.
- **Full-Screen Document Previews**: Ephemeral PDF viewer modal allowing students to inspect first-page previews before downloading.
- **Decrypted Instant Downloads**: Client-side document streaming with academic confetti feedback.
- **Real-Time Subject & Paper Search**: Multi-attribute query filter supporting subject names, course codes (`CSS 2101`), aliases, and topics.
- **Strict Minimalist Theme**: Strictly Black, White, and Light Brown (`sand`). Zero purple, zero distracting gradients.
- **Dual-Theme Engine**: Seamless toggle between Warm Ivory (`#FAF8F5`) and Deep Obsidian (`#08090C`) with zero flash-of-unthemed-content (FOUC).
- **Smooth Momentum Scrolling**: Hardware-accelerated smooth scrolling via Lenis synchronized with GSAP ticker loops.
- **Community Ingestion Protocol**: Dual contribution pathways (GitHub Fork/PR + Direct Email) with owner-controlled moderation.
- **Silent Background Analytics**: 100% privacy-preserving traffic and interaction tracking with automated GitHub README reporting.

```bash
cd pyq_clutch

# 2. Install dependencies
npm install

# 3. Start local development server
npm run dev

# 4. Build for production
npm run build

# 5. Preview production build
npm run preview
```

##  Adding New Question Papers (Maintainer Guide)

To add newly acquired question papers to the archive:
1. Optimize the PDF and verify all pages are legible and upright.
2. Save the file under: `public/pyqs/semester-3/endsem/<subject-id>/<year>/<paper-name>.pdf`.
3. Open `src/data/archiveData.ts` and locate the subject's entry.
4. Add the paper object under the corresponding year array:
   ```ts
   {
     id: 'ds-2025-makeup',
     title: 'Data Structures 2025 Makeup',
     subjectId: 'data-structures',
     subjectName: 'Data Structures',
     subjectCode: 'CSS 2101',
     year: 2025,
     variant: 'Makeup',
     fileUrl: '/pyqs/semester-3/endsem/data-structures/2025/ds-2025-makeup.pdf',
     thumbnailUrl: '/pyqs/semester-3/endsem/data-structures/2025/thumb-makeup.webp',
     pageCount: 3,
     fileSize: '1.4 MB',
     dateHeld: 'January 2025',
     topicsCovered: ['B-Trees', 'Graph Traversals', 'Hash Tables'],
   }
   ```
5. Run `npm run build` to verify type safety.

###  Analytics Philosophy & Security
- **Zero Frontend UI**: The website frontend displays **no** visitor counters, pageview numbers, or telemetry badges.
- **Privacy-First**: PostHog operates cookieless without gathering personally identifiable information (PII).
- **Automated Workflow**: `.github/workflows/update-analytics.yml` runs daily via GitHub Actions using secrets `POSTHOG_API_KEY` and `POSTHOG_PROJECT_ID`.
- **Safe Fallback**: If the PostHog API cannot be reached, existing statistics are preserved. Zeros or fabricated numbers are never written.
